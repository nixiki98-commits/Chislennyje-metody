## Задание 2. Среднее и стандартное отклонение

**Условие.** Реализовать среднее и std «в лоб» (сумма и сумма квадратов) и через `a.mean()`, `a.std()` на n = 10⁶. Проверить совпадение до 1e-12.

```python
def loop_mean_std(arr):
    n = len(arr)
    s = 0.0
    s2 = 0.0
    for x in arr:
        s += x
        s2 += x * x
    mean = s / n
    var = s2 / n - mean * mean
    return mean, math.sqrt(max(var, 0.0))

def numpy_mean_std(arr):
    return arr.mean(), arr.std()
```

| Способ | Время |
|---|--:|
| Обычный цикл Python | 191,93 мс |
| NumPy | 4,10 мс |
| **Ускорение** | **46,8×** |

Результаты совпадают с точностью до 1e-12:

```text
Python: среднее = 0,00008657747566395924   std = 0,9998534720462057
NumPy:  среднее = 0,00008657747566397438   std = 0,9998534720462114
```

**Вывод.** Разница между вариантами порядка 1e-15…1e-17, то есть требование 1e-12 выполнено. Формула «сумма квадратов минус квадрат среднего» вычитает близкие большие числа и теряет точность: на данных со средним 1e9 цикл выдаёт std = 0 (дисперсия получается отрицательной), а NumPy возвращает правильное значение около 1. NumPy сначала считает среднее, затем суммирует квадраты отклонений от него, а `sum` использует попарное суммирование, поэтому ошибка накапливается медленнее.

## Задание 10. Комбинированная маска

**Условие.** Выбрать элементы с `-1 < x < 1`: цикл против `a[(a > -1) & (a < 1)]`.

```python
def loop_mask(arr):
    return [x for x in arr if -1 < x < 1]

def numpy_mask(arr):
    return arr[(arr > -1) & (arr < 1)]
```

| Способ | Время |
|---|--:|
| Обычный цикл Python | 115,72 мс |
| NumPy | 6,82 мс |
| **Ускорение** | **17,0×** |

Результаты совпадают.

**Вывод.** Скобки в NumPy обязательны. Оператор `&` имеет более высокий приоритет, чем `>` и `<`, поэтому `a > -1 & a < 1` вычисляется как `a > (-1 & a) < 1`. Для float-массива это даёт `TypeError` (побитовое «и» не определено для float), для int-массива `ValueError` («неоднозначное значение массива»). В обоих случаях помогают скобки.

## Задание 11. Расстояния между точками

**Условие.** Матрица евклидовых расстояний `D[i, j] = ||X[i] − Y[j]||` для X и Y формы (1000, 3): двойной цикл против broadcasting.

```python
def numpy_dist(X, Y):
    return np.sqrt(((X[:, None, :] - Y[None, :, :]) ** 2).sum(axis=2))
```

- Размер временного массива (1000, 1000, 3): примерно **22,89 МБ**.

**Вывод.** Прямой broadcasting самый короткий, но самый затратный по памяти: временный массив (1000, 1000, 3) на ~23 МБ, плюс ещё один такой же при возведении в квадрат. Память можно сократить формулой через скалярное произведение (`X @ Y.T`), тогда хранится только матрица 1000 × 1000 (около 8 МБ), либо использовать `scipy.spatial.distance.cdist`.
